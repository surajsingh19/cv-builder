📖 Parameter Glossary ▼
System Prompt
The base instructions governing AI behavior (e.g., "Write clean Python code"). This is sent in every single turn.
Thinking Tokens (Internal Reasoning)
Invisible logic tokens generated by frontier models to solve complex problems before coding.
Context Payload (% of base code) per iteration
The existing codebase the AI must "re-read" to understand a fix. Higher values represent better "project memory".
New Code Generation (% of base code) per iteration
The actual new logic the AI produces. Even small fixes typically rewrite some part of the code.
Prototype Blueprint (Initial Input Prompt tokens)
The initial massive instructions used to build the very first version of the demo.
First-Draft Build (Output Code Tokens)
The total volume of code in the initial version. All refinement costs are calculated relative to this size.
Refinement Loops (Iterations)
The number of back-and-forth turns needed to polish the demo until it is client-ready. [even small dev fixes add to this count]
